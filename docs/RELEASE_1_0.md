# XR18 Studio 1.0.0

## Français

Première version 1.0 du logiciel : connexion XR18 sans redémarrage, parcours « Mon ingé son », paramètres matériels, retours, effets, scènes JSON v2, bibliothèque SQLite, droits et pont ReaCue. Conseiller local et dialogue OpenAI facultatif. Guides illustrés [FR](USER_GUIDE_FR.md) / [EN](USER_GUIDE_EN.md).

Installateurs autonomes Windows (installation par utilisateur en un clic), Mac Intel, Mac Apple Silicon, Linux AppImage et Debian. Aucun Node.js à installer. Les autorisations du système, le déplacement Mac vers Applications et l’autorisation d’exécution AppImage peuvent nécessiter des actions supplémentaires. Paquets non signés/non notariés.

Publication conditionnée à la réussite des tests et des quatre compilations, des tests de démarrage des paquets et des sommes SHA-256. Validation matérielle XR18/REAPER non réalisée ici : le numéro 1.0 ne constitue pas une certification concert. L’assistant n’entend pas le son. Les `.scn` contenant des FX textuels opaques sont archivables mais leur rappel reste bloqué ; utiliser X Air Edit puis capturer en JSON v2. Interface actuellement en français, documentation bilingue. Compatibilité vieux iPad non garantie.

## English

First 1.0 software release: XR18 connection without restarting, guided sound coach, hardware parameters, monitors, effects, JSON v2 scenes, SQLite library, permissions and ReaCue bridge. Local adviser and optional OpenAI dialogue. Illustrated [French](USER_GUIDE_FR.md) / [English](USER_GUIDE_EN.md) guides.

Self-contained installers: Windows per-user one-click installer, Intel Mac, Apple Silicon Mac, Linux AppImage and Debian package. No Node.js installation needed. OS approval, dragging the Mac app to Applications and allowing AppImage execution can require additional actions. Packages are unsigned and not notarized.

Publication requires successful tests, all four platform builds, packaged startup checks and SHA-256 checksums. Physical XR18/REAPER validation has not been performed here; 1.0 is not a concert certification. The adviser does not receive audio. Opaque textual FX in native `.scn` files block recall; load with X Air Edit and capture a JSON v2 scene. UI is currently French, documentation is bilingual. Old iPad compatibility is not guaranteed.
