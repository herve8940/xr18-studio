# Installation XR18 Studio

Le guide actuel remplace les anciennes instructions de développement :

- [Français : installation et tutoriel illustré](USER_GUIDE_FR.md)
- [English: installation and illustrated tutorial](USER_GUIDE_EN.md)
- [Télécharger / Download](https://github.com/herve8940/xr18-studio/releases/latest)

Pour développer depuis les sources : Node.js 22, `npm ci`, `npm --prefix web ci`, puis `npm run studio`. Ne pas confondre ce démarrage de développement avec les installateurs autonomes.
